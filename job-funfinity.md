# Funfinity — Backend / Game Server Developer (JD)

Ghi chú ôn: `notes/F-funfinity-interview-prep.md`. Tách riêng với SEADEV (`S-*`) và Agapi (`A-*`).

## Mô tả công việc
- Phát triển Backend/Game Server cho các sản phẩm game online phục vụ thị trường quốc tế.
- Thiết kế, xây dựng và phát triển kiến trúc hệ thống, API và logic gameplay phía Server.
- Phát triển các hệ thống Multiplayer, Guild, Ranking, Event, Matchmaking, Payment và các tính năng vận hành game.
- Xây dựng và tối ưu các dịch vụ hiệu năng cao bằng Java hoặc C++, đảm bảo khả năng mở rộng và xử lý lượng lớn người chơi đồng thời.
- Làm việc với Database, Redis/Cache, Network (TCP/UDP/WebSocket) và các hệ thống xử lý dữ liệu thời gian thực.
- Phân tích, tối ưu hiệu năng, Memory Usage, CPU, Multithreading và xử lý các bài toán Concurrency.
- Phối hợp với Game Designer, Client Developer và đội ngũ vận hành.
- Tham gia các dự án phát triển game cùng đối tác quốc tế.

## Yêu cầu
- Từ 03 năm kinh nghiệm phát triển phần mềm bằng Java.
- Ưu tiên đã phát triển Backend/Game Server hoặc dự án game online.
- Thành thạo Java Core hoặc Modern C++ (C++11/14/17+), OOP, Design Pattern.
- STL, Smart Pointer, Memory Management, RAII, tối ưu hiệu năng (C++).
- Multithreading, Concurrent Programming, Synchronization hoặc Lock-free Programming.
- Database (MySQL, PostgreSQL...), Redis hoặc Cache.
- Network Programming (TCP/UDP/WebSocket), Socket, giao thức truyền dữ liệu.
- Phân tích, tối ưu hiệu năng, xử lý bài toán hệ thống. Thành thạo Git.

## Điểm cộng
- Đã phát triển/vận hành game online (MMORPG, Turn-based, Card, Idle, Casual...).
- Game Server bằng C++/Java; Boost, Asio, gRPC, Protobuf, CMake.
- Dùng AI tool (ChatGPT, Claude, Copilot, Cursor).
- Unity, Cocos, Unreal. Linux, Docker, CI/CD, Microservices.
- Từng vận hành hệ thống phục vụ đồng thời hàng nghìn người chơi.
